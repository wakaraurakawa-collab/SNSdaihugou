# SNS大富豪 — 設計メモ

ゲームの「何が、どの数字で動いているか」をまとめる。コードの正はそれぞれのファイル（カッコ内）。数字を変えたら、この文書と画面内の「遊び方」も合わせる。

## 1. 立て付け

- あなたは架空のVtuber事務所「ネオンボックス」（`AGENCY`、仮の名前）の新人。同じ箱のメンバー（同期・先輩・後輩）とタイムラインで**話題と注目を奪い合う**
- 札 = 投稿のネタ。♠トーク（短文）・♥共感（写真）・♦告知・♣企画（配信）の4ジャンル
- 1局 = 1ヶ月。全員の順位が決まると月が進み、順位で**勢い**が増減。勢いが尽きると**卒業**（ゲームオーバー）。成績は配信を続けた月数
- 登場するものはすべて架空（事務所・配信者・企業・番組・ファン）。ドメインは `tl.local`

## 2. 大富豪のルール（engine.js）

- 札：♠♥♦♣ × 3〜2、ジョーカー 0〜2枚（既定1）。強さ 3 < 4 < … < K < A < 2 < JOKER
- 出し方：1枚／同じ数字 2〜4枚／同じマークで続く数字 3枚以上（階段）。ジョーカーは何にでもなる
- ローカルルール（タイトルの「対局の設定」で切り替え。`DEFAULT_RULES`）
  - 8切り（VIRAL）：8を出すと場が流れ、出した人から
  - 革命（SYSTEM UPDATE）：同じ数字4枚以上で強さが逆転。革命返しで戻る。アルゴリズム激変期は4枚以上の階段でも起きる
  - 縛り（GENRE LOCK）：同じマークが2回続くとそのマークしか出せない
  - 階段縛り（SERIES）：数字が1つずつ続くと次はその次の数字だけ
  - 11バック（REVERSE）：Jで場が流れるまで強さが逆転
  - スペ3返し（FACT CHECK）：ジョーカー1枚に♠3で返せる
  - 都落ち（DOWNFALL）：前の月の覇権が1位を逃すと、その時点でオワコン
  - 反則上がり：ジョーカー・2・8・♠3（返し）で上がると最下位
  - カード交換：2ヶ月目から。オワコン→覇権に2枚、過疎→人気者に1枚。もらった側は好きな札を返す。新しい期生は中堅扱い
- 身分（`titlesFor(n)`）：4人 覇権・人気者・過疎・オワコン、5人以上は真ん中が中堅、3人は覇権・中堅・オワコン
- CPU（`aiChoose`）：`easy / normal / hard`。hard は手番中にモンテカルロ（`thinkMC`、最大120回）。各メンバーの気質（`TEMPERS`：慎重派・強気・気分屋・策士）で、パスのしやすさと揺らぎが変わる
- 席順：あなたが席0（手前）。手番は時計回り。前の月の順位で交換の組が決まる

## 3. 勢い（dynasty.js）

- 開始 10、最大 25（`START_POWER` / `MAX_POWER`）。0以下で卒業
- 月末の増減（`basePowerDelta`）：覇権 +4／人気者 +2／中堅 ±0／過疎 −1／オワコン −(3 + 2×連続回数)
- 毎月マンネリ −1（`UPKEEP`。1期生デビュー期は 0、てぇてぇ期は 0）
- 箱の時期の補正：看板の時代は上位 +1・下位 −1、てぇてぇ期は増減がゆるやか（マイナス半分・プラス 2/3）、アルゴリズム激変期は革命1回につき +2（最大 +4）、ブームの冬は全員 −1
- `powerOutlook(h, state, n, rev)`：今月の順位ごとの月末の勢いの見込み。「何位以下なら卒業か」（`deadPos`）は圧の仕組みと結果画面の警告に使う。`test/followers-unit.js` で `resolveGeneration` と一致することを確認している

## 4. 登録者（dynasty.js）

- 投稿するたびに増える、勢いとは別の積み上げの数字。登録者が多くても勢いがなければオワコン
- 1枚あたり `followerUnit(F, s) = 2·1.55^s + F/(1+F/1.5e6)·0.0006·1.38^s`（`FOL`）。s は札の強さ 0〜13（革命・11バック中は逆転）
  - 8切り → s≥10、スペ3返し → 13.5、革命 → +2×(s=12 の分)、複数枚 ×(1+0.15(n−1))、揺らぎ ×0.85〜1.15
- 月末の割合（`followerRate`）：覇権 +8%／人気者 +4%／中堅 0／過疎 −3%／オワコン −6%（続くと −9%、−12%…、最大 −20%）。てぇてぇ期は半分、ブームの冬は −5%
- 節目（1,000・1万・10万・100万…）を越えるとファンからお祝いのDM。月の途中の増加は `Fol.month` に貯め、月末に本体へ足す（途中では保存しない）
- 開始：あなた 0、同期 20〜499、後から入る期生 150〜4,000

## 5. 投稿の規模（段階）と箱の時期（dynasty.js / 23-posts.js / 24-content.js）

- 段階 ①初配信期 ②駆け出し ③中堅 ④人気 ⑤看板 = min(活動月数の段階, 登録者の段階)
  - 月数のしきい値 1 / 3 / 7 / 13 / 25、登録者 0 / 1,000 / 1万 / 10万 / 50万（`STAGE_AGE` / `STAGE_FOL`）
  - 3期生以降は月数の段階が1つ上から（箱が大きくなっているぶん）
  - 段階は月の始めの登録者で決める（月の途中で文面が変わらない）
- 札の文面は `POSTS[suit][rank]` に段階ごと5つ（null は前の段階を引き継ぐ）。ジョーカーは `JOKER_POSTS`。いいねの幅（`BUZZ_RANGE`）、サムネの視聴者数（`VIEW_BASE`）、告知の帯、短文の印も段階で変わる
- 段階が上がった月は、月の始めに「○○入り STAGE UP」を告げ、マネージャーから一言届く（`stageUpProclaim`、`h.stageSeen` に記録）
- 箱の時期（`ERA_DEFS`）：1期生デビュー → 後輩デビューラッシュ／看板の時代／てぇてぇ期／アルゴリズム激変期／ブームの冬 を重み付きで巡る。時期ごとに人数の目標（3〜7人）、新しい期生のデビュー、勢いの補正が変わる。7 と ♥6 の文面、トレンド・DMの一部は時期と立場（前の月の覇権／いちばん新しい後輩）で差し替わる
- 期生（`ki`）：同じ月にデビューした人は同期。最初の4人が1期生。古い保存には `ensureFollowers()` がデビュー月の順で振る

## 6. 同接・勢いゲージ（37-desk.js）

- 窓の「● LIVE」の数字 = 同接。基準 `viewerBase(p, F) = min(2·1.25^p + F·0.0005·1.18^p, 20 + 0.6F)`
- 0.65〜2.1秒ごとに揺らぎ、投稿で跳ね（強い札ほど、8切り・スペ3・革命は大きく）、パスが続くと減り、上がると「終了」
- 勢いは数字と細いゲージ（25で金色、5以下で赤）

## 7. 通知と事務所からの圧（38-notify.js / 39-pressure.js）

- 前の月に人気者・覇権だと、DM・コラボ（同期・先輩・後輩・ときどき他事務所）・案件・ファンアート・投げ銭、覇権は出演依頼・取材も。中身はあなたの段階に合わせる
- ファンは約90人のプール（`FAN_BASES` + `FAN_SOLO` + 肩書き）。アイコンは顔ではなく `26-fanicon.js` の29種（猫・風景・アニメ風・推し活グッズ・ごはん）
- 1位で上がった月：ファンから「今月もたくさんトレンド入りしてましたね！」のような配信者としての活躍への反応（ゲームの仕組みには触れない）
- **運営**：オワコンが2ヶ月続くと不穏な連絡（続くほど重く）。30秒以内に既読にしないと念押し
- **催促**：勢いが2ヶ月続けて下がると「改善して」
- **卒業の危機**：`powerOutlook` で今月の順位しだいで卒業になるとき。月の始めに「卒業の危機 DANGER」、自分の欄が赤く脈打ち「卒業危機」の印。マネージャーが投稿・パス・止まった手（14秒）・ほかのメンバーの上がり（残り枠）に口を出す。同じ月に同じ文は言わない（`Pressure.said`）。上がって回避すると「セーフ」、枠が埋まると「卒業濃厚」
- **覇権キープ**：覇権が2ヶ月以上続いている月（卒業の危機でないとき）。月の始めに「今が頑張りどきです。絶対に落とさないでください」と褒めながら圧をかけ、投稿（42%）・パス・止まった手・1位の行方に口を出す。1位なら「はい、来月の話をしましょう」、落とすと「……覇権陥落。『絶対に落とさないで』と言いましたよね」。ファンからも「今月も覇権、期待してます！」
- 月末の結果画面にも「来月、○○以下なら卒業です」「覇権○ヶ月連続。来月も1位でなければ都落ち」と出す
- 文言はすべて `39-pressure.js` の上のほうの配列（`DANGER_START` / `NAG_FX` / `SUIT_NAG` / `TITLE_NAG` / `PASS_NAG` / `FINISH_NAG` / `PEAK_*` / `FALLING_*` / `COMPANY_*` / `FAN_WORRY`）にある。数字だけ違う文は同じ文とみなして、同じ月に二度言わない

## 8. 月末の結果（40-ui.js）

- 順位・勢いの増減（内訳）・登録者の増減（投稿／おすすめ／登録解除）
- 出来事：卒業・吸収（看板の時代）・デビュー・時期の変わり目
- **今月のハイライト**（`MonthStats`）：いちばんバズった投稿（ジョーカーの ∞ は除く）・トレンド1位・いちばん静かだった人（パス3回以上）
- 警告：卒業ライン／オワコン継続／勢いが残りわずか

## 9. 画面と演出

- ふだんは**白地に黒い文字**（`:root`）。**革命中だけ黒地に白い文字**（`:root[data-mood="dark"]`）。切り替えはグリッチ＋フラッシュ。月末には白に戻す
- 中央にタイムライン、まわりに各メンバーの「ブラウザ窓」。PC は左右の列、スマホ縦は上の一列、横長は小さく詰める（`30-layout.js`）
- 演出：8切り = 稲妻 VIRAL、縛り = マークの形の鎖と錠前、階段縛り = 連番の段、11バック = 紫の縁、革命 = UPDATE パネル、ジョーカー = グリッチ、スペ3 = FACT CHECK の判
- 効果音はすべて WebAudio で合成（`Sound.play`）。音のオン・オフは保存される

## 10. バランスの目安（test/survival-sim.js）

CPU（ふつう）にあなたを任せたとき：中央値 17ヶ月、四分位 10〜33ヶ月、4ヶ月未満で卒業 2%、覇権になる月 22%（300回）。つよい CPU で中央値 23ヶ月、よわい CPU で 6ヶ月。人間が「ふつう」の相手と遊んで 10〜30ヶ月くらい続く想定。
