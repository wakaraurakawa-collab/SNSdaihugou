## 決めたこと（経緯）

- もとは西洋風の「大富豪興亡記（家の興亡）」。SNS でインフルエンサーが話題を奪い合う立て付けに変え、さらに「事務所からデビューした Vtuber 同士の箱の中の戦い」にした。名残り：`localStorage` の旧キー `daifugo-chronicle:*` から設定と音だけ引き継ぐ
- 「チップ」は捨てて「同接」に。影響力は「勢い」と呼ぶ（増えると覇権、落ちるとオワコン）
- フォロワー → 登録者、引退 → 卒業、新人 → ○期生、♠言論 → トーク
- 投稿の規模は 5 段階で育つ（デビュー1ヶ月目に世界規模のバズは出さない）。段階は活動月数と登録者の低いほう
- 事務所名「ネオンボックス」は**仮**。変えるなら `dynasty.js` の `AGENCY` と `src/page.html` のタイトル画面の文言
- ふだんは白基調・革命中だけダーク（v12 で反転した。v11 までは逆）
- 卒業の危機・運営の不穏な DM・マネージャーのマイクロマネジメントは v11 で追加。1位の月のファンの DM は「ゲームの仕組みに触れない」文面にする方針

## 既知の問題・気になっているところ

- 月の途中で閉じると、その月の進行は失われる（保存は月末だけ）。再開は月の始めから
- 画面テストで1度だけ `errors: 2` が出たことがあるが再現せず、中身は未確認（テスト用サーバーの読み込み失敗の疑い。`test/shot.cjs` は今は中身も出す）
- `hard` の CPU は手番ごとに最大 ~0.5 秒考える。古い端末では少し待たされるかもしれない
- 窓が7つ＋スマホ横（844×390）はかなり詰まる。読めるが余裕はない
- `old/` にあった旧デザインのモジュールは v13 で削除した（git の履歴にもない）

## やりたいことの候補

- 事務所名・箱の雰囲気を選べるようにする（タイトルで事務所を選ぶ）
- 月の途中の保存（手番ごとに `game` を保存する。engine の状態は JSON にできる）
- 実績・称号（「初配信期で覇権」「10ヶ月連続人気者以上」など）と、タイトル画面の履歴
- CPU メンバーにも段階アップや卒業のドラマ（本人の DM、卒業配信の投稿）
- マネージャーに名前と顔をつける／口調を選べるようにする
- 音量スライダー、BGM（合成）
- ローカライズ（英語）：文面はすべて `23-posts.js` / `38-notify.js` / `39-pressure.js` / `page.html` に集まっている

## テストの使い方

```bash
npm run build && npm test
npm run serve &                   # 8766。落ちていたら立て直す
node test/shot.cjs play 390 844   # 1局を自動で進めて場面ごとに撮る
node test/shot.cjs long 1280 800  # 卒業まで早送り
node test/audit.cjs 390x844       # タイトル〜卒業まで全画面
node test/stageup.cjs 1280x800    # 段階アップと月末のハイライト
node test/scenarios/danger.cjs 1280x800 2 2 a fast   # 卒業の危機の月（勢い2・オワコン2連続）
node test/scenarios/danger.cjs 1280x800 20 -3 pk fast # 覇権キープの月（勢い20・覇権3ヶ月連続）
node test/scenarios/notes.cjs 1280x800 大富豪          # 覇権の月の通知
node test/scenarios/oldsave.cjs                        # 前の版の保存データの読み込み
node test/scenarios/fanicons.cjs 64                    # ファンのアイコン一覧
node test/scenarios/stages.cjs                         # 全札×5段階の文面を書き出す（test/_shots/stages.txt）
```

スクリーンショットは `test/_shots/`（gitignore 済み）に出る。`SHOT_OUT` / `SHOT_BASE` / `CHROME_PATH` で変えられる。
