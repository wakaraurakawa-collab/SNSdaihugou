# SNS大富豪

架空のVtuber事務所「ネオンボックス」からデビューした新人として、同じ箱のメンバーと**話題と注目を奪い合う**、SNS風の大富豪です。
札は投稿のネタ。1局が1ヶ月で、順位によって「勢い」が増減し、勢いが尽きると卒業。卒業せずに何ヶ月配信を続けられるかを競います。

- ブラウザで動く **1ファイルのHTML**（`dist/sns-daifugo.html`）。外部読み込みは Google Fonts だけ
- PC・スマホ縦・スマホ横に対応。進行は月末ごとに自動保存（`localStorage`）
- 登場する事務所・配信者・企業・番組・ファンはすべて架空。実在のSNSのロゴや著名人の肖像は使いません

## 遊び方（かんたんに）

- 手札の札をタップして選び「投稿」。ドラッグでまとめて選べ、同じ札をダブルタップすると同じ数字をまとめて選びます
- ふつうの大富豪のルール（8切り・革命・縛り・階段縛り・11バック・スペ3返し・都落ち・反則上がり・カード交換）をSNSの演出で遊びます
- 投稿するたびに登録者が増え、月末には順位で勢い（最大25）が増減。覇権 +4／人気者 +2／中堅 ±0／過疎 −1／オワコン −3（続くと −5、−7…）、毎月マンネリで −1
- 勢いが0以下になると卒業（ゲームオーバー）。成績は配信を続けた月数
- 詳しいルール・数字は画面内の「遊び方」と [docs/DESIGN.md](docs/DESIGN.md)

## 開発

```bash
npm install                 # playwright-core と、画面テスト用フォント（@fontsource）
npm run build               # src/ → dist/sns-daifugo.html, test/index.html, test/_bundle.mjs
npm test                    # ルール・登録者・人数のユニットテスト（Node だけで動く）
npm run sim                 # バランス確認：CPU にあなたを任せて何ヶ月続くか
npm run serve               # http://127.0.0.1:8766（画面テスト用のローカルサーバー）
npm run shots               # 画面のスクリーンショット（serve を立てたうえで。test/_shots/ に出る）
```

画面テストには Chromium が要ります。`npx playwright install chromium` か、`CHROME_PATH=/path/to/chrome` で指定します（詳細は `test/_env.cjs`）。

### 構成

```
build.py          src/ を1枚の HTML に束ねる（モジュールの順番はここ）
src/page.html     画面の骨組みと CSS（/*__SCRIPT__*/ の位置に JS が入る）
src/engine.js     大富豪のルールエンジンと CPU 思考（Node でもブラウザでも動く）
src/dynasty.js    箱の月日：勢い・登録者・卒業・箱の時期・期生（Node でもブラウザでも動く）
src/js/*.js       画面（番号順に束ねる。下の表）
test/             ユニットテスト・シミュレーション・Playwright の画面テスト
docs/             設計メモと引き継ぎメモ
dist/             ビルド結果（公開する1ファイル）
```

| src/js | 役割 |
| --- | --- |
| 10-util | 小道具：補間（Tween）、効果音（WebAudio 合成）、localStorage |
| 20-svg / 22-avatar | マークの形、ドット絵アイコン（髪型・表情） |
| 23-posts | 札の文面（4種×13段×5段階）と時期ごとの差し替え |
| 24-content | 文面の解決（段階・立場）、いいね数、同接の目安、架空アカウント |
| 25-paint | 札の表をキャンバスに描く |
| 26-fanicon | ファンのアイコン（猫・風景・推し活グッズなどの SVG） |
| 30-layout | 画面の割り付け（中央のタイムライン・まわりの窓・手札） |
| 35-cards | 札の要素と手札の並び |
| 37-desk | 窓・タイムライン・トレンド・同接・縛りの鎖・月の記録（ハイライト） |
| 38-notify | 通知：DM・コラボ・案件・運営・マネージャー、受信箱 |
| 39-pressure | 事務所からの圧：卒業の危機、催促、マイクロマネジメント |
| 40-ui | 操作パネル・結果画面・卒業画面・遊び方の凡例 |
| 50-flow | 進行：月の始まり → 配る → 交換 → 手番 → 月末 |
| 60-boot | 起動・入力・キーボード・タイトル画面 |
