        Vtuber事務所「ネオンボックス」の、箱の中の話題争奪戦

        あなたは事務所からデビューしたばかりの新人Vtuber。札は投稿のネタ。強い投稿で同じ箱のメンバーから注目を奪い、ネタを出し切ったら勝ち。投稿するたびに登録者が増え、全員の順位が決まるたびに1ヶ月が経って、順位で勢いが増減。勢いが尽きたら卒業。卒業せずに何ヶ月、配信を続けられるか。

              話題と注目の奪い合い

              • 目的は卒業せずに配信を続けること。成績は、配信を続けられた月数です。
              • あなたはVtuber事務所「ネオンボックス」からデビューした新人Vtuber。まわりは同じ箱のメンバー（同期・先輩・後輩）です。手札は投稿のネタで、札を出すことが投稿・配信を公開すること。
              • より強い札で上回る＝話題性の高い投稿で注目を奪う。ほかの全員がパスすると話題終了（場が流れる）で、最後に出した人が次の話題を始めます。場が流れるまでの投稿が、タイムラインの1つの話題（スレッド）です。
              • ネタ（手札）を最初に出し切った人が勝ち。勝ち負けはふつうの大富豪と同じです。
              • 連続でパス（割り込めない）が続くと、顔アイコンがだんだん焦っていきます（平常→気になる→焦り→狼狽）。話題をさらうと勝ち誇ります。パスに罰はありません。

              数字が大きいほど話題の規模も大きくなります（いいねや視聴者の数も増えていきます）。強さは 3 < 4 < … < K < A < 2 < ジョーカー。

              投稿の規模は少しずつ育つ

              • 投稿の中身は、そのメンバーの段階で変わります。①初配信期（1〜2ヶ月目）→ ②駆け出し（3〜6ヶ月目・登録者1,000人〜）→ ③中堅（7〜12ヶ月目・1万人〜）→ ④人気（2年目・10万人〜）→ ⑤看板（3年目〜・50万人〜）。
              • 段階は、活動月数と登録者数の低いほうで決まります。3期生以降のメンバーは、箱が大きくなっているぶん活動月数の段階が1つ上から始まります（登録者が足りていれば）。
              • 札の強さは「その段階の中での大きさ」です。同じ2でも、新人なら「登録者1,000人記念配信」、看板なら「アリーナライブ決定」。いいねの数も段階に合わせて育ちます。世界規模の話題は看板になってから。
              • 箱の時期によって、7（バトン）や♥6の投稿がその時期らしい話題になります（1期生デビューなら同期、後輩デビューラッシュなら先輩・後輩の話）。

              月日と勢い

              • 1局を遊んで全員の順位が決まると、1ヶ月が経ちます。
              • 各メンバーには勢い（いまの旬。いわば体力）があり、局の順位で増減します。勢いに乗れば覇権、勢いを失えばオワコン。0以下になると卒業です。あなたが卒業したら終わりです。
              • 毎月、マンネリで勢いが1落ちます。上位に入らなければ少しずつ失速します。
              • 窓の「● LIVE」の数字は同接（いま配信を見ている人）。勢いと登録者で水準が決まり、細かく増えたり減ったりします。投稿すると跳ね上がり、パスが続くと減っていき、ネタを出し切ると「終了」。登録者が多くても、勢いがなければ同接は伸びません。
              • 勢いそのものは、同接の横の小さな数字と細いゲージで見えます（最大25。25で金色、5以下は赤）。
              • オワコンが続くと減り方が大きくなります（−3、−5、−7…）。カード交換で強い札を取られるので、抜け出すのは簡単ではありません。
              • ほかのメンバーも勢いが尽きれば卒業してタイムラインから去り（窓が閉じる）、箱の時期によっては新しい期生がデビューします。同じ月にデビューした人は同期です。参加する人数は3〜7人で変わります。

              登録者

              • 札を出す（投稿する）たびにチャンネル登録者が増えます。強い札ほど大きく増え、いまの登録者が多いほど届く人も増えます。8切り（VIRAL）・革命・スペ3返しはとくに伸びます。
              • 革命や11バックで強さが逆転しているあいだは、数字の小さい札ほど伸びます（いいねの数も逆転します）。
              • 月末には順位でも増減します。覇権・人気者は「おすすめ」に載って増え、過疎・オワコンは「登録解除」で減ります（上の表）。
              • 登録者は勢いとは別の数字です。積み上がっていくので、登録者が多くても勢いがなければオワコンです。卒業するかどうかは勢いだけで決まります。

              人気者になると

              • 前の月に人気者・覇権だと、その月は画面の端（スマホは上）にDM・コラボのお誘い・案件の相談・ファンアート・投げ銭などの通知がときどき届きます。コラボは同期・先輩・後輩から（ときどき他事務所から）、案件や出演の話はマネージャー経由で届きます。覇権になると出演依頼や取材も来ます。中身はあなたの段階に合わせて大きくなります。
              • 大きな投稿をすると反応のDMが届きやすくなります。1位で上がった月や、登録者が節目を越えたときは、ファンからお祝いも届きます。
              • 届いた通知は上のベルで見返せます。順位が落ちると、通知はぱったり来なくなります。

              事務所からの連絡

              • 調子が落ちると、人気と関係なく事務所から連絡が来ます。オワコンが2ヶ月続くと、運営から不穏な連絡が届きます（既読をつけないと念押しも）。勢いが2ヶ月続けて下がると、マネージャーから「改善して」と催促が届きます。
              • 今月の順位しだいで勢いが尽きる月は卒業の危機です。月の始めに「今月、過疎以下なら卒業」のように告げられ、あなたの欄が赤く光って卒業危機の印が付きます。
              • 卒業の危機の月は、マネージャーが出した投稿・続くパス・止まった手・ほかのメンバーの上がりに、いちいち口を出してきます（残りの枠も教えてくれます）。上がって卒業を避けられれば印は「セーフ」に、枠が埋まると「卒業濃厚」になります。
              • 逆に覇権が2ヶ月以上続くと、今度は「今が頑張りどきです。絶対に落とさないでください」と、褒めながら圧をかけてきます。都落ちがあるので、覇権が1位を逃すと一気にオワコンです。

              箱の時期

              大富豪の基本

              • 場が空なら好きな出し方で出せます。場にカードがあるときは、同じ形・同じ枚数で、より強いものだけ出せます。
              • 形は「1枚」「同じ数字を2〜4枚」「同じマークで続いた数字を3枚以上（階段＝連続投稿）」。ジョーカーはどの札の代わりにもなります。
              • 出せない・出したくないときはパス。
              • 2ヶ月目からは、前の月のオワコンが覇権へ最強の2枚、過疎が人気者へ最強の1枚を渡し、もらった側は好きな札を返します。新しい期生は中堅として扱います。

              ローカルルールと演出

              8切り
              VIRAL。8だけの出し方（8の1枚・ペアなど）で場が流れ、出した人からまた始めます。7-8-9のような階段に8が入っていても切れません。
              革命
              SYSTEM UPDATE（アルゴリズム更新）。同じ数字4枚以上で強さが逆転し、画面が黒地に白い文字の暗いモードになります（ふだんは白い画面）。ジョーカーは最強のまま。
              階段革命
              4枚以上の階段でも革命。
              縛り
              ジャンル固定。直前と同じマークが続くと、場が流れるまでそのマークしか出せません。タイムラインがそのマークの形の鎖で囲まれます。
              階段縛り
              連番シリーズ。直前の札と数字がちょうど1つ続くと（例：5→6、ペアなら5のペア→6のペア）、場が流れるまで続きの数字しか出せません（6→7→8…）。革命中・11バック中は下へ続きます（例：10→J と出て11バックになると、次は10）。縛りも重なって必要な札がもう出ていれば、出せるのはジョーカーだけです。
              11バック
              REVERSE（タイムライン逆転）。Jを出すと、場が流れるまで強さが逆転。
              スペ3返し
              FACT CHECK（「ソースあります？」）。1枚出しのジョーカーには♠3で勝てます。
              ジョーカー
              GLITCH。全SNSの電波が混線したような最強の札。
              覇権陥落
              （都落ち）前の月の覇権が1位で上がれないと、その時点でオワコン。
              反則上がり
              ジョーカー・2（革命中は3）・8切り・スペ3返しで上がると、規約違反で最下位。

              画面の見方

              • まんなかがタイムライン。場に出た札は、出した人の投稿として流れます。場が流れるまで投稿はスレッドとしてつながり、新しい投稿が上に積まれます。いちばん上の投稿が、いま上回るべき札です。
              • 場が流れると、その話題は#タグ付きのトレンドになって下に残ります（「〇〇さんが△△で注目」と、話題の大きさに応じたポスト数）。
              • まわりのブラウザの窓が同じ箱のほかのメンバーです。手番の順に時計回りに並びます（あなたは手前。左の列を下から上へ、右の列を上から下へ。スマホでは上の列を左から右へ）。
              • 窓には残りの札（裏向きの札の数）、同接（LIVE）と勢い、登録者数、顔アイコンが出ます。手番の人の窓が光り、タブが読み込み中になります。
